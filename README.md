## 🌐 GitHub Pages

1. Create a GitHub repository for the portfolio.
2. Upload `index.html`, `style.css`, `script.js` and `profile.png`.
3. Go to **Settings → Pages**.
4. Select **Deploy from a branch → main → /root**.
5. Save and open the generated GitHub Pages URL.
